App del empleado — instalación

Proyecto Flutter independiente para el handheld de pista. Android primero; iOS es opcional.

1 · Obtener el código

git clone https://github.com/Carlosomar601/RM-GASOLINA-BROKER.git
cd RM-GASOLINA-BROKER/apps/employee_app

2 · Generar las carpetas nativas

flutter create . --project-name employee_app --platforms=android
flutter pub get

Es un proyecto Flutter independiente de la app del cliente — no comparte pubspec.yaml, aunque copia el mismo sistema visual (paleta, tipografía, componentes).

3 · Modo demo vs. broker real

Sin variables, corre con la cola de órdenes de demostración:

flutter run

Para conectarlo al broker (esto activa la pantalla de abrir turno con placa + PIN; handheld ya publicado como web en https://empapp.retailmanagerpr.com/#/turno):

flutter run --dart-define=OCTANO_API=https://rmbroker.retailmanagerpr.com

El handheld guarda el turno entre arranques (placa, estación y rol) — no vuelve a pedir el PIN salvo que el token venza o se cierre sesión.

4 · Dar de alta a un empleado

Cada empleado necesita una fila en la tabla employees del broker con su placa, PIN (cifrado) y estación asignada — se administra desde el panel de administración o directamente por API. Sin esto, el login del handheld rechaza la entrada.

5 · Generar el instalable

flutter build apk --release --dart-define=OCTANO_API=https://rmbroker.retailmanagerpr.com
# el APK queda en build/app/outputs/flutter-apk/app-release.apk

Instala ese APK en el handheld físico de la estación (transferencia directa o un canal de distribución interno — no hace falta tienda de apps para uso propio).

Solución de problemas

  • Placa o PIN incorrectos: confirma que el empleado exista en esa estación específica — la placa es única por estación, no global.
  • La cola no se actualiza sola: revisa el indicador LIVE/CLOUD/OFF de la barra superior; si dice OFF, es un problema de red del handheld, no del broker.
  • No aparece la pantalla de turno: falta el --dart-define=OCTANO_API=… al compilar — sin él, la app siempre abre en modo demo.
