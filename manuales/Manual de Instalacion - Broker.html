MANUAL DE INSTALACIÓN · BROKER (NODE + POSTGRES)

Broker Octano — instalación y arranque

API que conecta las apps móviles con Retail Manager y el controlador PTS-2. Node 20 + Fastify + Postgres.

Requisitos

  • Node.js 20.11 o más reciente.
  • Postgres 14 o más reciente (local, o el `docker-compose.yml` incluido).
  • Acceso de red a Retail Manager y al controlador PTS-2/PTS2Link de cada estación.

1 · Obtener el código

git clone https://github.com/Carlosomar601/RM-GASOLINA-BROKER.git
cd RM-GASOLINA-BROKER/apps/broker

2 · Levantar Postgres

Con Docker (más rápido para desarrollo):

docker compose up -d

O apunta DATABASE_URL a un Postgres que ya tengas corriendo.

3 · Variables de entorno

Copia .env.example a .env y ajusta:

Importante: los endpoints reales de Retail Manager y PTS2Link de cada estación NO van en .env — se administran por API (/v1/admin/integrations) y quedan cifrados en la base con MASTER_KEY. Ver el manual del proyecto completo.

4 · Instalar y preparar la base

npm install
npm run migrate
npm run seed        # datos de la estación de desarrollo (opcional)

5 · Arrancar

npm run dev          # desarrollo, recarga automática
# — o para producción —
npm run build
npm start

Confirma que está vivo:

curl http://localhost:8090/health

Debe responder {"status":"ok", "db": true, ...}.

6 · Configurar una estación nueva

  1. Crea el operador (tenant) y la estación vía /v1/admin/tenants y /v1/admin/stations.
  2. Registra sus integraciones (rm_api, pts2link, payments) vía /v1/admin/integrations — cada una con su propia base URL y credenciales.
  3. Prueba cada enlace con /v1/admin/integrations/:id/test.
  4. Revisa la configuración final que usará el broker en /v1/admin/stations/:id/effective-config.
  5. Carga bombas, mangueras y tanques (ver semilla de ejemplo en db/migrations/002_seed_dev.sql como plantilla).

Solución de problemas

SíntomaCausa probable
/health responde db: falseDATABASE_URL incorrecta o Postgres no está corriendo.
Falta la variable de entorno XNo se copió .env.example a .env, o falta esa clave.
Las apps no autenticanJWT_SECRET cambió entre reinicios — invalida todas las sesiones activas.
Una integración guardada deja de descifrarMASTER_KEY cambió — hay que volver a capturar esos secretos.
Facturas atascadas en rm_outboxRetail Manager no responde; usa POST /v1/admin/outbox/retry cuando vuelva.
